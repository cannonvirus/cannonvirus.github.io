{{- /* 그림 아래 설명은 제목(`![대체 문구](경로 "설명")`)을 적은 그림에만 붙인다. 그래프는 그림 안에 제목이 있어 설명을 적지 않는다. 보고서형(layout: report)에서는 모든 그림에 "그림 N." 캡션을 붙인다. 제목이 없으면 대체 문구를 쓴다. 캡션 끝의 "(출처: …)"는 따로 떼어 작은 글자로 적고, report.html이 글 끝 그림 출처 목록에 모은다. */ -}} {{- $report := eq .Page.Layout "report" -}} {{- $no := add .Ordinal 1 -}} {{- $caption := .Title -}} {{- if and $report (not $caption) }}{{ $caption = .PlainText }}{{ end -}} {{- $source := "" -}} {{- with $caption }}{{ with findRESubmatch `^(.*?)\s*\(출처:\s*(.+)\)\s*$` . 1 }}{{ $caption = index (index . 0) 1 }}{{ $source = index (index . 0) 2 }}{{ end }}{{ end -}} {{- /* 글 묶음 안의 그림은 가로·세로 크기를 적어 그림이 뜰 때 본문이 밀리지 않게 한다. PNG(그래프·화면 캡처)는 무손실 webp로, JPG(사진)는 손실 webp(q85)로 바꾸고 긴 변을 1600px 이하로 줄인다. 바꾼 것이 원본보다 크면 원본을 쓴다. webp·GIF는 이미 압축된 파일이라 다시 압축하지 않는다. */ -}} {{- $src := .Destination -}} {{- $size := "" -}} {{- with .Page.Resources.Get .Destination -}} {{- $img := . -}} {{- $spec := index (dict "png" "webp lossless" "jpeg" "webp q85") .MediaType.SubType -}} {{- with $spec -}} {{- $new := "" -}} {{- if gt $img.Width 1600 }}{{ $new = $img.Resize (printf "1600x %s" .) }}{{ else }}{{ $new = $img.Process . }}{{ end -}} {{- if lt (len $new.Content) (len $img.Content) }}{{ $img = $new }}{{ end -}} {{- end -}} {{- $src = $img.RelPermalink -}} {{- $size = printf ` width="%d" height="%d"` $img.Width $img.Height -}} {{- end -}}
